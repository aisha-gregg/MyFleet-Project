# MyFleet product brief

MyFleet helps small and mid-sized fleets track vehicles, coach drivers, and cut fuel and maintenance costs.
This brief is the single source of truth for product names and capabilities used across the portfolio.

## Product line

| Product | Type | Description |
|---------|------|-------------|
| **MyFleet MT-100** | Hardware | Plug-and-play tracker for the vehicle's diagnostic (OBD) port. No wiring needed. Green LED shows power; blue LED shows a cellular connection. |
| **MyFleet MT-200** | Hardware | Plug-in vehicle tracker with GPS, 4G LTE-M, and a CAN bus interface. Installs behind the dashboard in about 30 minutes. |
| **MyFleet MT-200 Pro** | Hardware | MT-200 with a driver ID reader and two digital inputs for PTO and door sensors. |
| **MyFleet Driver App** | Software (iOS, Android) | Lets drivers log in to a vehicle, view assigned jobs, run pre-trip checks, and see driving-style feedback. |
| **MyFleet Dashboard** | Software (web) | Live map, trip history, reports, alerts, and user management for fleet managers. |
| **MyFleet API** | Developer platform | REST API for vehicles, positions, trips, drivers, and webhooks. |
| **MyFleet OEM Connect** | Partner integration | Receives vehicle data directly from manufacturer cloud platforms, with no hardware installation. |

## Audiences

- **Fleet managers:** use the Dashboard daily. Want quick answers, not theory.
- **Drivers:** use the Driver App on the road. Low patience for long text; often non-native English speakers.
- **Installers:** fit MT-200 devices. Work in vehicles, often from a phone.
- **Developers and partners:** integrate through the API or OEM Connect. Need accurate, complete reference material.

## Markets and languages

MyFleet sells in the UK, Ireland, Spain, France, Belgium, and Mexico.
Customer content ships in English (UK), Spanish (Spain), Spanish (Mexico), and French (France).

## Release cadence

- **Software:** quarterly feature releases (for example 4.2), with monthly maintenance updates.
- **Firmware:** two releases a year, plus security patches as needed.
- **API:** versioned (`v2` current). Breaking changes get 6 months' notice.
