# MyFleet content style guide

This guide keeps MyFleet content consistent across formats, markets, and languages.
It also makes translation cheaper and more accurate: shorter, simpler source text means fewer errors.

## Voice

- **Clear over clever.** Write for someone reading on a phone in a cab.
- **Direct.** Use "you" and the active voice. "Plug the tracker into the OBD port", not "The tracker should be plugged in".
- **Calm.** Warnings state the risk and the fix, without drama.

## Writing for translation

- Keep sentences under 25 words. One instruction per step.
- Do not use idioms, jokes, or culture-specific references.
- Use the same term for the same thing every time (see the [glossary](glossary.md)).
- Avoid text in images. If you must, keep the editable source file.
- Leave 30% extra space in print layouts: Spanish and French text runs longer than English.

## Formatting

| Element | Rule | Example |
|---------|------|---------|
| UI labels | Bold, match the UI exactly | Select **Save** |
| Product names | Full name on first use | MyFleet Driver App, then Driver App |
| Code, endpoints, values | Code format | `GET /v2/vehicles` |
| Numbers | Numerals for 10 and above; always numerals with units | 5 m, 12 V |
| Dates | Day month year in prose; ISO 8601 in data | 9 November 2026; `2026-11-09` |

## Procedures

1. Start with a one-line goal ("To add a driver, ...").
2. List prerequisites before step 1.
3. Start each step with a verb.
4. End with a result the user can check ("The vehicle appears on the live map").

## Admonitions

- **Note:** helpful extra information.
- **Important:** something that can cause a task to fail.
- **Warning:** a risk of injury, vehicle damage, or data loss. Use sparingly.

## Spelling

Source content uses UK English to match the primary market.
