# Glossary

Approved terms for MyFleet content. Translators receive this list as the termbase for every project.

| Term | Definition | Do not use | ES (Spain) | FR (France) |
|------|------------|------------|------------|-------------|
| tracker | The MT-200 or MT-200 Pro device installed in a vehicle | box, unit, black box | localizador | traceur |
| vehicle | Any asset with a tracker installed | truck, car (unless specific) | vehículo | véhicule |
| trip | Movement from ignition on to ignition off | journey, ride | trayecto | trajet |
| driver ID | The key fob or card a driver uses to log in to a vehicle | tag, chip | identificación del conductor | identifiant conducteur |
| live map | The real-time map view in the Dashboard | tracking map | mapa en tiempo real | carte en temps réel |
| geofence | A virtual boundary that triggers an alert on entry or exit | zone, fence | geocerca | géorepérage |
| pre-trip check | The vehicle inspection a driver completes before a trip | walkaround | revisión previa al trayecto | contrôle avant départ |
| webhook | An HTTP callback MyFleet sends when an event occurs | push notification | webhook | webhook |
| API key | The secret used to authenticate API requests | token (unless OAuth) | clave de API | clé API |
| OEM Connect | Integration that receives data from manufacturer clouds | OEM integration (as a name) | OEM Connect | OEM Connect |

!!! important "Do not translate"
    Product names (MyFleet, MT-200, Driver App, OEM Connect) and code stay in English in every language.
