## Content that ships with each release

For every feature release, the following are published on release day in all supported languages:

- release notes
- updated user and installation guides in the knowledge base
- API changelog and updated reference
- updated Product Availability Matrix (quarterly)

## Subscribe

Partners can subscribe to release notifications in the Partner Portal under **Notifications > Releases**.
