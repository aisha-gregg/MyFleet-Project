# Video script: Installing the MT-200 in 4 minutes

**Format:** screen and hands-on footage, voice-over · **Length:** about 4 minutes
**Source article:** [KB-0101](mt200-installation.md) · **Subtitles:** EN, ES, FR

!!! note "For translators"
    Voice-over lines are kept under 15 words so subtitles fit two lines. On-screen text is kept as separate layers so it can be localized without re-editing.

| # | Time | Visual | Voice-over | On-screen text |
|---|------|--------|-----------|----------------|
| 1 | 0:00 | MyFleet logo, van in a workshop | In this video, you'll install a MyFleet MT-200 tracker and test it. | Install the MT-200 |
| 2 | 0:08 | Items laid on a bench | You need the tracker, the harness, a multimeter, and the Installer app. | What you need |
| 3 | 0:20 | Close-up: hand removing battery terminal | First, disconnect the negative battery terminal. | ⚠ Disconnect the battery |
| 4 | 0:30 | Behind dashboard, pointing to location | Mount the tracker behind the dashboard, label side up, away from airbags. | 30 cm from airbags |
| 5 | 0:50 | Wires being connected, colour callouts | Connect black to ground, red to permanent power, white to ignition. | Black · Red · White |
| 6 | 1:40 | Multimeter on ignition wire | Check the ignition wire reads zero volts with the ignition off. | 0 V = ignition off |
| 7 | 2:00 | Battery reconnected, LED flashing amber | Reconnect the battery. The amber light means it's searching for a network. | |
| 8 | 2:20 | Phone screen: scanning QR code | In the Installer app, select New installation and scan the QR code. | New installation |
| 9 | 2:50 | Ignition on, LED turns green | Turn on the ignition and wait for a solid green light. | Solid green = connected |
| 10 | 3:10 | Phone: Run test, "Installation passed" | Select Run test. When you see Installation passed, you're done. | Installation passed ✓ |
| 11 | 3:40 | Dashboard live map with new vehicle | The vehicle now appears on the live map. | |
| 12 | 3:50 | End card with KB link | For troubleshooting, see the full article in the MyFleet knowledge base. | help.myfleet.example/KB-0101 |
